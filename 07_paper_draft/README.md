# 07_paper_draft

`latex/` holds the LaTeX source of the paper as submitted to ICCIES 2027
(Springer CCIS, LNCS class `llncs.cls` v2.25, bibliography style `splncs04.bst`).

Build: `pdflatex main`, `bibtex main`, then `pdflatex main` twice (or open the folder on Overleaf).
Editing comments were removed from `main.tex` and `refs.bib`; the typeset text is unchanged.

`latex/` chứa nguồn LaTeX của bài, đúng bản nộp ICCIES 2027 (Springer CCIS, khuôn LNCS).
Biên dịch: `pdflatex main`, `bibtex main`, rồi `pdflatex main` hai lần (hoặc mở thư mục trên Overleaf).
Các dòng chú thích dùng khi soạn bài đã được bỏ khỏi `main.tex` và `refs.bib`; chữ in ra không đổi.
